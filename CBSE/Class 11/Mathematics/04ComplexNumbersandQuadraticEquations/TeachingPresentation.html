Vardaan Learning Institute Topic 1 — The Imaginary Unit 04
Concept Why Do We Need Complex Numbers?
The Problem

In $\mathbb{R}$: $x^2 = -1$ has no real solution because for all $x \in \mathbb{R}$:

$$x^2 \geq 0$$

So the equation $x^2 + 1 = 0$ cannot be solved in $\mathbb{R}$.

The Solution — Introducing $i$

We define a new symbol $i$ (iota) such that:

$$\boxed{i = \sqrt{-1} \qquad \Longleftrightarrow \qquad i^2 = -1}$$
Consequence

For any $a > 0$:   $\sqrt{-a} = \sqrt{a \times (-1)} = \sqrt{a} \cdot \sqrt{-1} = i\sqrt{a}$

Examples:   $\sqrt{-4} = 2i$    $\sqrt{-9} = 3i$    $\sqrt{-7} = i\sqrt{7}$

Caution Critical Rule: Multiplication of Negative Square Roots
⚠ NCERT Special Note — Very Frequently Tested!

$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ holds ONLY when both $a \geq 0$ and $b \geq 0$

When $a < 0$ or $b < 0$, you must FIRST convert to $i$ form.

❌ WRONG Approach
$$\sqrt{-2} \times \sqrt{-3} = \sqrt{(-2)(-3)} = \sqrt{6}$$

This is INCORRECT! ❌

✔ CORRECT Approach
$$\sqrt{-2} \times \sqrt{-3} = (i\sqrt{2})(i\sqrt{3}) = i^2\sqrt{6} = -\sqrt{6}$$

This is CORRECT! ✔

Solution Q1 Express in $i$ Form — Step-by-Step Solution

(i) $\sqrt{-25} = \sqrt{25}\times i = 5i = \mathbf{0 + 5i}$   (Real part = $0$, Imaginary part = $5$)

Vardaan Learning Institute Topic 2 — Solution 13
Solution Q3 Real & Imaginary Parts — Step-by-Step Solution
✔ Detailed Step-by-Step Solution

For any complex number $z = a + ib$, by definition $\text{Re}(z) = a$ and $\text{Im}(z) = b$ (real scalar, without $i$).

(i) $z = 5 - 3i \implies \mathbf{\text{Re}(z) = 5}, \quad \mathbf{\text{Im}(z) = -3}$.

(ii) $z = -7i = 0 - 7i \implies \mathbf{\text{Re}(z) = 0}, \quad \mathbf{\text{Im}(z) = -7}$   (Purely imaginary number).

(iii) $z = 2\sqrt{3} = 2\sqrt{3} + 0i \implies \mathbf{\text{Re}(z) = 2\sqrt{3}}, \quad \mathbf{\text{Im}(z) = 0}$   (Purely real number).

(iv) $z = (2-i)^2 = 2^2 - 2(2)(i) + i^2 = 4 - 4i - 1 = 3 - 4i \implies \mathbf{\text{Re}(z) = 3}, \quad \mathbf{\text{Im}(z) = -4}$.

(v) $z = \dfrac{1}{1+i} = \dfrac{1-i}{(1+i)(1-i)} = \dfrac{1-i}{1 - i^2} = \dfrac{1-i}{2} = \dfrac{1}{2} - \dfrac{1}{2}i \implies \mathbf{\text{Re}(z) = \dfrac{1}{2}}, \quad \mathbf{\text{Im}(z) = -\dfrac{1}{2}}$.

⚠ Critical Exam Warning

Never write $\text{Im}(z) = -3i$ or $\text{Im}(z) = -4i$. The imaginary part is strictly the real coefficient multiplying $i$!

Question 4 NCERT Ex 5.1 Q1

Find real values of $x$ and $y$ if $(x - iy)(3 + 5i)$ is the conjugate of $(-6 - 24i)$.

Solution Space
Vardaan Learning Institute Topic 2 — Solution 15
Solution Q4 Equality — Find $x$ and $y$ — Full Solution
✔ Detailed Step-by-Step Solution

Given: $(x - iy)(3 + 5i) = \overline{-6 - 24i}$.

Step 1: Evaluate RHS conjugate: $\overline{-6 - 24i} = -6 + 24i$.

Step 2: Expand LHS: $(x - iy)(3 + 5i) = 3x + 5xi - 3yi - 5yi^2 = (3x + 5y) + i(5x - 3y)$.

Step 3: Equate real and imaginary parts:

     (1)   $3x + 5y = -6$          (2)   $5x - 3y = 24$

Step 4: Multiply (1) by $3$ and (2) by $5$:   $9x + 15y = -18$   and   $25x - 15y = 120$.

Adding both equations:   $34x = 102 \implies \mathbf{x = 3}$.

Substitute $x = 3$ in (1):   $3(3) + 5y = -6 \implies 9 + 5y = -6 \implies 5y = -15 \implies \mathbf{y = -3}$.

Final Answer: $\mathbf{x = 3}, \quad \mathbf{y = -3}$

Practice Q5 Equality — Proof Problem
Question 5 RS Aggarwal CBSE 2020

If $(x + iy)^3 = u + iv$, then show that $\dfrac{u}{x} + \dfrac{v}{y} = 4(x^2 - y^2)$.

Solution Space
Vardaan Learning Institute Topic 2 — Solution 17
Solution Q5 Equality Proof — Step-by-Step Solution
✔ Detailed Step-by-Step Solution

Given: $(x + iy)^3 = u + iv$.

Step 1: Expand LHS using algebraic identity $(A + B)^3 = A^3 + 3A^2B + 3AB^2 + B^3$:

     $(x + iy)^3 = x^3 + 3x^2(iy) + 3x(iy)^2 + (iy)^3 = x^3 + 3ix^2y - 3xy^2 - iy^3$

     $= (x^3 - 3xy^2) + i(3x^2y - y^3) = u + iv$.

Step 2: Equating real and imaginary parts:

     $u = x^3 - 3xy^2 = x(x^2 - 3y^2) \implies \mathbf{\dfrac{u}{x} = x^2 - 3y^2}$    (Eq. 1)

     $v = 3x^2y - y^3 = y(3x^2 - y^2) \implies \mathbf{\dfrac{v}{y} = 3x^2 - y^2}$    (Eq. 2)

Step 3: Adding Eq. 1 and Eq. 2:

     $\dfrac{u}{x} + \dfrac{v}{y} = (x^2 - 3y^2) + (3x^2 - y^2) = 4x^2 - 4y^2 = \mathbf{4(x^2 - y^2)}$.

✔ Conclusion

$\dfrac{u}{x} + \dfrac{v}{y} = 4(x^2 - y^2)$. Hence Proved!

Vardaan Learning Institute Topic 3 — Solution 26
Solution Q8 Multiplicative Inverse — Step-by-Step Solution
✔ Detailed Step-by-Step Solution

Recall Master Formula: $\mathbf{z^{-1} = \dfrac{\bar{z}}{|z|^2} = \dfrac{a - ib}{a^2 + b^2}}$.

(i) $z = 4 - 3i$:

     $\bar{z} = 4 + 3i, \quad |z|^2 = 4^2 + (-3)^2 = 16 + 9 = 25 \implies \mathbf{z^{-1} = \dfrac{4 + 3i}{25} = \dfrac{4}{25} + \dfrac{3}{25}i}$.

(ii) $z = \sqrt{5} + 3i$:

     $\bar{z} = \sqrt{5} - 3i, \quad |z|^2 = (\sqrt{5})^2 + 3^2 = 5 + 9 = 14 \implies \mathbf{z^{-1} = \dfrac{\sqrt{5} - 3i}{14} = \dfrac{\sqrt{5}}{14} - \dfrac{3}{14}i}$.

(iii) $z = -i = 0 - i$:

For (iii): $z \cdot z^{-1} = (-i)(i) = -i^2 = -(-1) = 1$. Multiplicative identity holds!

Solution Q10 Evaluate Powers of $i$ — Step-by-Step Solution

Recall Master Law: $i^4 = 1$. Divide each exponent by $4$ and write in the form $4k + r$ where $r \in \{0, 1, 2, 3\}$.

Vardaan Learning Institute Topic 4 — Solution 36
Solution Q12 Least Positive Power — Step-by-Step Solution
✔ Detailed Blackboard Working

Given Equation:   $\left(\dfrac{1+i}{1-i}\right)^n = 1$

1
Simplify the Base Fraction $\dfrac{1+i}{1-i}$ by Multiplying by Conjugate:

$\dfrac{1+i}{1-i} = \dfrac{1+i}{1-i} \times \dfrac{1+i}{1+i} = \dfrac{(1+i)^2}{1^2 - i^2}$

2
Expand and Substitute $i^2 = -1$:

$\dfrac{(1+i)^2}{1 - (-1)} = \dfrac{1 + 2i + i^2}{1 + 1} = \dfrac{1 + 2i - 1}{2} = \dfrac{2i}{2} = \mathbf{i}$

3
Substitute Back into Original Equation:

$\left(\dfrac{1+i}{1-i}\right)^n = 1 \implies \mathbf{i^n = 1}$

4
Determine the Least Positive Integer Value of $n$:

Recall the cyclic powers of $i$:   $i^1 = i$,   $i^2 = -1$,   $i^3 = -i$,   $i^4 = 1$.
In general, $i^n = 1 \iff n = 4k$ (where $k \in \mathbb{Z}^+$).
For the least positive integer, choose $k = 1 \implies \mathbf{n = 4}$.

Final Answer:   The least positive value of $n$ is   $\mathbf{n = 4}$   ■ Q.E.D.

✔ Rigorous Step-by-Step Proof

Given Equation:   $\dfrac{a+ib}{c+id} = x + iy \quad \dots\text{--- (1)}$

Part (i): Proof of $\dfrac{a-ib}{c-id} = x - iy$

     Taking the complex conjugate on both sides of equation (1):

$\overline{\left(\dfrac{a+ib}{c+id}\right)} = \overline{x + iy}$

     Using the conjugate quotient property $\overline{\left(\dfrac{z_1}{z_2}\right)} = \dfrac{\bar{z}_1}{\bar{z}_2}$ and $\overline{u+iv} = u - iv$:

$\dfrac{\overline{a+ib}}{\overline{c+id}} = x - iy \implies \mathbf{\dfrac{a-ib}{c-id} = x - iy} \quad \dots\text{--- (2)}$

     Hence Part (i) is proved!

Part (ii): Proof of $\dfrac{a^2+b^2}{c^2+d^2} = x^2 + y^2$ — (Two Standard Methods)

Method A: Multiply Equations (1) & (2)

$\left(\dfrac{a+ib}{c+id}\right)\left(\dfrac{a-ib}{c-id}\right) = (x+iy)(x-iy)$

$\dfrac{(a+ib)(a-ib)}{(c+id)(c-id)} = (x+iy)(x-iy)$

$\dfrac{a^2 - (ib)^2}{c^2 - (id)^2} = x^2 - (iy)^2$   (since $i^2 = -1$)

$\mathbf{\dfrac{a^2+b^2}{c^2+d^2} = x^2 + y^2}$   ■ Proved

From (1): $\left|\dfrac{a+ib}{c+id}\right| = |x+iy|$

$\dfrac{|a+ib|}{|c+id|} = |x+iy| \implies \dfrac{\sqrt{a^2+b^2}}{\sqrt{c^2+d^2}} = \sqrt{x^2+y^2}$

Squaring both sides (S.B.S):

$\mathbf{\dfrac{a^2+b^2}{c^2+d^2} = x^2 + y^2}$   ■ Proved

Solution Q18 Proof: Purely Imaginary — Rigorous Step-by-Step Proof
✔ Detailed Step-by-Step Proof

Goal: Show that $w = \dfrac{z - i}{z + i}$ is purely imaginary given $|z| = 1$.

Criterion: A complex number $w$ is purely imaginary if and only if $\mathbf{\bar{w} = -w}$ (i.e. $w + \bar{w} = 0$).

Step 1: Take the complex conjugate of $w$:

     $\bar{w} = \overline{\left(\dfrac{z - i}{z + i}\right)} = \dfrac{\bar{z} - \bar{i}}{\bar{z} + \bar{i}} = \dfrac{\bar{z} + i}{\bar{z} - i}$.

Step 2: Use the property $|z| = 1 \implies |z|^2 = z\bar{z} = 1 \implies \mathbf{\bar{z} = \dfrac{1}{z}}$. Substitute this into $\bar{w}$:

     $\bar{w} = \dfrac{\frac{1}{z} + i}{\frac{1}{z} - i} = \dfrac{\frac{1 + iz}{z}}{\frac{1 - iz}{z}} = \dfrac{1 + iz}{1 - iz}$.

Step 3: Multiply numerator and denominator by $i$ (noting $i^2 = -1$):

     $\bar{w} = \dfrac{i(1 + iz)}{i(1 - iz)} = \dfrac{i + i^2 z}{i - i^2 z} = \dfrac{i - z}{i + z} = -\dfrac{z - i}{z + i} = \mathbf{-w}$.

Conclusion: Since $\bar{w} = -w \implies w + \bar{w} = 0 \implies 2\,\text{Re}(w) = 0$, $w$ is purely imaginary. ■ Q.E.D.

Solution Q19 HOTS Modulus Evaluation — Step-by-Step Proof
✔ Complete Blackboard Working via $|z|^2 = z\bar{z}$

Goal: Find $\left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right|$ given $|\beta| = 1$.

Step 1: Use the Fundamental Modulus Identity $|Z|^2 = Z \cdot \bar{Z}$:

$\left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right|^2 = \left(\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right) \overline{\left(\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right)} = \left(\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right)\left(\dfrac{\bar{\beta} - \bar{\alpha}}{1 - \overline{\bar{\alpha}\beta}}\right) = \left(\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right)\left(\dfrac{\bar{\beta} - \bar{\alpha}}{1 - \alpha\bar{\beta}}\right)$

Step 2: Expand the Numerator:

$\text{Num} = (\beta - \alpha)(\bar{\beta} - \bar{\alpha}) = \beta\bar{\beta} - \beta\bar{\alpha} - \alpha\bar{\beta} + \alpha\bar{\alpha} = |\beta|^2 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2$

Since $|\beta| = 1 \implies |\beta|^2 = 1$, we get:   $\mathbf{\text{Num} = 1 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2}$

Step 3: Expand the Denominator:

$\text{Den} = (1 - \bar{\alpha}\beta)(1 - \alpha\bar{\beta}) = 1 - \alpha\bar{\beta} - \bar{\alpha}\beta + (\bar{\alpha}\beta)(\alpha\bar{\beta}) = 1 - \bar{\alpha}\beta - \alpha\bar{\beta} + (\alpha\bar{\alpha})(\beta\bar{\beta}) = 1 - \bar{\alpha}\beta - \alpha\bar{\beta} + |\alpha|^2|\beta|^2$

Substitute $|\beta|^2 = 1$:   $\mathbf{\text{Den} = 1 - \bar{\alpha}\beta - \alpha\bar{\beta} + |\alpha|^2}$

Step 4: Cancel and Conclude:

$\left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right|^2 = \dfrac{1 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2}{1 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2} = \mathbf{1} \implies \left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right| = \sqrt{1} = \mathbf{1}$

Final Result:   $\mathbf{\left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right| = 1}$   ■ Q.E.D.

Solution Q32 Step-by-Step Proof: Purely Imaginary

Goal: Let $w = \dfrac{z_1+z_2}{z_1-z_2}$. A complex number $w$ is purely imaginary (or zero) if and only if $w + \bar{w} = 0$ (i.e. $\text{Re}(w) = 0$).

Step 1: Express $\bar{w}$ using properties of conjugates:

     $\bar{w} = \overline{\left(\dfrac{z_1+z_2}{z_1-z_2}\right)} = \dfrac{\bar{z}_1+\bar{z}_2}{\bar{z}_1-\bar{z}_2}$.

Step 2: Add $w$ and $\bar{w}$ over a common denominator:

     $w + \bar{w} = \dfrac{z_1+z_2}{z_1-z_2} + \dfrac{\bar{z}_1+\bar{z}_2}{\bar{z}_1-\bar{z}_2} = \dfrac{(z_1+z_2)(\bar{z}_1-\bar{z}_2) + (\bar{z}_1+\bar{z}_2)(z_1-z_2)}{(z_1-z_2)(\bar{z}_1-\bar{z}_2)}$.

Step 3: Expand the numerator:

     $\text{Numerator} = (z_1\bar{z}_1 - z_1\bar{z}_2 + z_2\bar{z}_1 - z_2\bar{z}_2) + (\bar{z}_1 z_1 - \bar{z}_1 z_2 + \bar{z}_2 z_1 - \bar{z}_2 z_2)$.

     $\implies \text{Numerator} = 2z_1\bar{z}_1 - 2z_2\bar{z}_2 = 2(|z_1|^2 - |z_2|^2)$.

Step 4: Use the given condition $|z_1| = |z_2|$:

     Since $|z_1| = |z_2| \implies |z_1|^2 = |z_2|^2 \implies |z_1|^2 - |z_2|^2 = 0$.

     $\left[\left(\dfrac{1+i}{1-i}\right)^3 - \left(\dfrac{1-i}{1+i}\right)^3\right] = (i)^3 - (-i)^3$.

Step 3: Evaluate the powers of $i$:

     Recall: $i^3 = -i$,   and   $(-i)^3 = (-1)^3 \cdot i^3 = -1 \cdot (-i) = i$.

     $\implies (i)^3 - (-i)^3 = (-i) - (i) = \mathbf{-2i}$.

Step 4: Standard Cartesian form $a + ib$:

     $\mathbf{0 - 2i}$ (where $a = 0$, $b = -2$).

Final Evaluated Answer:   $\mathbf{\left[\left(\dfrac{1+i}{1-i}\right)^3 - \left(\dfrac{1-i}{1+i}\right)^3\right] = -2i = 0 - 2i}$

Vardaan Learning Institute Miscellaneous — Solution 93
Solution Q34 Modulus of Complex Expression
Direct Modulus Property Method

Given: $z_1 = 2 - i$ and $z_2 = 1 + i$.

Step 1: Simplify the Numerator:

     $N = z_1 + z_2 + 1 = (2 - i) + (1 + i) + 1 = (2 + 1 + 1) + (-i + i) = \mathbf{4}$.

Step 2: Simplify the Denominator:

     $D = z_1 - z_2 + i = (2 - i) - (1 + i) + i = 2 - i - 1 - i + i = (2 - 1) + (-i - i + i) = \mathbf{1 - i}$.

Step 3: Compute individual moduli:

     $|N| = |4| = 4$.

     $|D| = |1 - i| = \sqrt{1^2 + (-1)^2} = \sqrt{1 + 1} = \mathbf{\sqrt{2}}$.

Step 4: Apply the quotient rule for modulus $\left|\dfrac{N}{D}\right| = \dfrac{|N|}{|D|}$:

     $\left|\dfrac{z_1+z_2+1}{z_1-z_2+i}\right| = \dfrac{|N|}{|D|} = \dfrac{4}{\sqrt{2}} = \dfrac{4\sqrt{2}}{2} = \mathbf{2\sqrt{2}}$.

Final Result:   $\mathbf{\left|\dfrac{z_1+z_2+1}{z_1-z_2+i}\right| = 2\sqrt{2}}$

Question 35 CBSE 2022 HOTS

If $z = x + iy$ and $w = \dfrac{1-iz}{z-i}$, show that $|w| = 1$ implies that $z$ is real.

Solution Space   [Hint: $|w|=1 \Rightarrow |1-iz|=|z-i|$. Let $z=x+iy$ and expand.]
Vardaan Learning Institute Miscellaneous — Solution 95
Solution Q35 HOTS Proof: Modulus & Real Axis
Geometric & Cartesian Proof

Given: $w = \dfrac{1-iz}{z-i}$ with $|w| = 1$, where $z = x + iy$.

Step 1: Set up the modulus equation:

     $|w| = 1 \iff \left|\dfrac{1-iz}{z-i}\right| = 1 \iff \dfrac{|1-iz|}{|z-i|} = 1 \iff |1-iz| = |z-i|$.

     Squaring both sides:   $|1-iz|^2 = |z-i|^2$.

Step 2: Express both sides in terms of $x$ and $y$:

     For LHS:   $1 - iz = 1 - i(x + iy) = 1 - ix - i^2y = (1 + y) - ix$.

     $\implies |1 - iz|^2 = (1 + y)^2 + (-x)^2 = 1 + 2y + y^2 + x^2$.

     For RHS:   $z - i = x + iy - i = x + i(y - 1)$.

     $\implies |z - i|^2 = x^2 + (y - 1)^2 = x^2 + y^2 - 2y + 1$.

Step 3: Equate LHS and RHS:

     $1 + 2y + y^2 + x^2 = x^2 + y^2 - 2y + 1$.

     Cancel $x^2$, $y^2$, and $1$ from both sides:   $2y = -2y \implies 4y = 0 \implies \mathbf{y = 0}$.

Conclusion:

     Since $y = \text{Im}(z) = 0$, we have $z = x + 0i = x \in \mathbb{R}$.

     Hence, $z$ lies completely on the real axis (i.e., $z$ is purely real).   $\blacksquare$

HOTS Insight:   $|w| = 1 \iff |1 - iz|^2 = |z - i|^2 \iff 4y = 0 \iff y = 0 \implies z \text{ is purely real}$
