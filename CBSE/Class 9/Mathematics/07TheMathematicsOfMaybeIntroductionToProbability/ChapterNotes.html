The Mathematics of Maybe: Introduction to Probability

1. Fundamental Concepts of Probability

Probability is a quantitative measure of the likelihood that an uncertain event will occur.

Terminology
  • Random Experiment: An activity with well-defined outcomes that cannot be predicted with certainty in advance.
  • Outcome: A possible result of a random experiment.
  • Sample Space ($S$): The set of all possible outcomes.
  • Event ($E$): Any subset of the sample space.

2. Formula and Fundamental Properties

$$\mathbf{P(E) = \frac{\text{Number of outcomes favorable to } E}{\text{Total number of possible outcomes}} = \frac{n(E)}{n(S)}}$$
Key Probability Rules
  • Range of Probability: $0 \le P(E) \le 1$
  • Impossible Event: An event that cannot happen has $P(E) = 0$.
  • Sure / Certain Event: An event guaranteed to happen has $P(E) = 1$.
  • Complementary Event ($\bar{E}$ or $E'$): The event "not $E$". $$\mathbf{P(E) + P(\bar{E}) = 1} \implies \mathbf{P(\bar{E}) = 1 - P(E)}$$

3. Solved Examples

Example 1: Tossing Two Fair Coins

Question: Two coins are tossed simultaneously. Find the probability of getting at least one head.

Solution:

1. Sample Space $S = \{HH, HT, TH, TT\}$, so $n(S) = 4$.

2. Favorable outcomes for "at least one head" $E = \{HH, HT, TH\}$, so $n(E) = 3$.

$$P(E) = \frac{n(E)}{n(S)} = \frac{3}{4} = 0.75$$
Example 2: Rolling a Die & Complementary Event

Question: A single die is rolled. Find the probability of NOT getting a multiple of $3$.

Solution:

Sample Space $S = \{1, 2, 3, 4, 5, 6\} \implies n(S) = 6$.

Multiples of $3$: $M = \{3, 6\} \implies n(M) = 2$.

$$P(M) = \frac{2}{6} = \frac{1}{3}$$

Probability of NOT getting a multiple of $3$:

$$P(\bar{M}) = 1 - P(M) = 1 - \frac{1}{3} = \frac{2}{3}$$

4. Summary

Quick Checklist
  • Probability can never be negative or greater than $1$.
  • The sum of probabilities of all elementary events of an experiment is equal to $1$.
