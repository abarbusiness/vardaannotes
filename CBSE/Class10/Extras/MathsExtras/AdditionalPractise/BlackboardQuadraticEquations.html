QUESTION 01 Standard Form & Identification CBSE Board Core
Check whether \( (x + 1)^2 = 2(x - 3) \) is a quadratic equation. If yes, express it in standard form \( ax^2 + bx + c = 0 \) and state the values of \( a, b, c \).
Given Equation: \( (x + 1)^2 = 2(x - 3) \)
01 / 50
Detailed Solution 01
Step 1: Expand LHS:
\( x^2 + 2x + 1 = 2x - 6 \)

Step 2: Rearrange to RHS = 0:
\( x^2 + 2x - 2x + 1 + 6 = 0 \implies x^2 + 7 = 0 \)

Conclusion: Yes, it is a quadratic equation of degree 2 with \( a = 1, b = 0, c = 7 \).
QUESTION 02 Factorisation Method CBSE Board Standard
Solve the quadratic equation \( 2x^2 - 5x + 3 = 0 \) by middle-term splitting factorisation.
Given Equation: \( 2x^2 - 5x + 3 = 0 \)
02 / 50
Detailed Solution 02
Splitting Middle Term: Product = \( 2 \times 3 = 6 \), Sum = \( -5 \). Factors: \( -2 \) and \( -3 \).

\( 2x^2 - 2x - 3x + 3 = 0 \)
\( 2x(x - 1) - 3(x - 1) = 0 \)
\( (2x - 3)(x - 1) = 0 \)

Roots: \( x = \frac{3}{2} \) or \( x = 1 \).
QUESTION 03 Factorisation with Radicals CBSE High Yield
Find the roots of the quadratic equation \( \sqrt{2} x^2 + 7x + 5\sqrt{2} = 0 \) using factorisation.
Given Equation: \( \sqrt{2} x^2 + 7x + 5\sqrt{2} = 0 \)
03 / 50
Detailed Solution 03
Product of ac: \( \sqrt{2} \times 5\sqrt{2} = 10 \). Split 7 into \( 5 + 2 \):

\( \sqrt{2} x^2 + 2x + 5x + 5\sqrt{2} = 0 \)
\( \sqrt{2} x(x + \sqrt{2}) + 5(x + \sqrt{2}) = 0 \)
\( (\sqrt{2} x + 5)(x + \sqrt{2}) = 0 \)

Roots: \( x = -\frac{5}{\sqrt{2}} = -\frac{5\sqrt{2}}{2} \) or \( x = -\sqrt{2} \).
