Type A1 — Find All Ratios When One is Given (Using Pythagoras)

Solved Example 1

Q. If sin θ = 5/13, find all other trigonometric ratios.

Step 1 — Identify P and H

P = 5, H = 13

Step 2 — Find B via Pythagoras

$B = \sqrt{H^2-P^2} = \sqrt{169-25} = \sqrt{144} = 12$

Step 3 — Write all ratios

$\cos\theta = \dfrac{12}{13}$, $\tan\theta = \dfrac{5}{12}$, $\csc\theta = \dfrac{13}{5}$, $\sec\theta = \dfrac{13}{12}$, $\cot\theta = \dfrac{12}{5}$

Type A2 — Find Ratios When Given in the Form of a Product/Quotient (Reciprocal or Quotient Given)

Solved Example 2

Q. If 15 cot A = 8, find sin A and sec A.

cot A = 8/15 → B = 8, P = 15, $H = \sqrt{64+225} = 17$

$\sin A = \dfrac{15}{17}$, $\sec A = \dfrac{17}{8}$

Type A3 — Evaluate Expression When One Ratio is Given

Solved Example 3

Q. If tan θ = 4/3, find $\dfrac{3\sin\theta + 2\cos\theta}{3\sin\theta - 2\cos\theta}$.

Find sides: P=4, B=3, H=5

$\sin\theta = 4/5$, $\cos\theta = 3/5$

$= \dfrac{3\cdot\frac{4}{5} + 2\cdot\frac{3}{5}}{3\cdot\frac{4}{5} - 2\cdot\frac{3}{5}} = \dfrac{\frac{12}{5}+\frac{6}{5}}{\frac{12}{5}-\frac{6}{5}} = \dfrac{18}{6} = \mathbf{3}$

Type A4 — Divide Numerator & Denominator by cos θ or sin θ (Do NOT Find Sides)

Solved Example 4

Q. If tan θ = 7/8, evaluate $\dfrac{(1+\sin\theta)(1-\sin\theta)}{(1+\cos\theta)(1-\cos\theta)}$.

$(1+\sin\theta)(1-\sin\theta) = 1-\sin^2\theta = \cos^2\theta$

$(1+\cos\theta)(1-\cos\theta) = 1-\cos^2\theta = \sin^2\theta$

$= \dfrac{\cos^2\theta}{\sin^2\theta} = \cot^2\theta = \dfrac{1}{\tan^2\theta} = \dfrac{1}{(7/8)^2} = \dfrac{64}{49}$

Type A5 — Ratios Given as a Ratio (e.g., sin A : cos A = 3 : 4)

Solved Example 5

Q. If sin A : cos A = 3 : 4, find sin A, cos A, and tan A.

Let sin A = 3k and cos A = 4k. Use $\sin^2 A + \cos^2 A = 1$:

$9k^2 + 16k^2 = 1$ → $25k^2 = 1$ → $k = 1/5$

$\sin A = \dfrac{3}{5}$, $\cos A = \dfrac{4}{5}$, $\tan A = \dfrac{3}{4}$

Type A6 — Show That an Expression Has a Specific Value (Given a Trig Ratio)

Solved Example 6 (ML Aggarwal Type)

Q. If sin θ = a/b, show that $\sec\theta + \tan\theta = \sqrt{\dfrac{b+a}{b-a}}$.

P = a, H = b, $B = \sqrt{b^2-a^2}$

$\sec\theta = \dfrac{b}{\sqrt{b^2-a^2}}$, $\tan\theta = \dfrac{a}{\sqrt{b^2-a^2}}$

$\sec\theta + \tan\theta = \dfrac{b+a}{\sqrt{b^2-a^2}} = \dfrac{b+a}{\sqrt{(b+a)(b-a)}} = \sqrt{\dfrac{(b+a)^2}{(b+a)(b-a)}} = \sqrt{\dfrac{b+a}{b-a}}$ ✓

Type B1 — Direct Evaluation (Substitute Values)

Solved Example 7

Q. Evaluate: $2\sin^2 45° + 3\cos^2 30° - \tan^2 60° + \cot^2 45°$

$= 2\cdot\dfrac{1}{2} + 3\cdot\dfrac{3}{4} - 3 + 1 = 1 + \dfrac{9}{4} - 3 + 1 = \dfrac{4+9-12+4}{4} = \dfrac{5}{4}$

Type B2 — Find the Angle θ from a Trig Equation

Solved Example 8

Q. Find acute angle θ if: (i) $2\cos^2\theta - 1 = 0$   (ii) $\tan 2\theta = \sqrt{3}$   (iii) $\sec 2\theta = \text{cosec}(3\theta - 20°)$

(i)

$\cos^2\theta = \frac{1}{2}$ → $\cos\theta = \frac{1}{\sqrt{2}}$ → $\theta = 45°$

(ii)

$\tan 2\theta = \sqrt{3} = \tan 60°$ → $2\theta = 60°$ → $\theta = 30°$

(iii) — Complementary Angle Equation

$\sec 2\theta = \csc(3\theta-20°)$ → Since $\sec\alpha = \csc(90°-\alpha)$:

$2\theta + (3\theta - 20°) = 90°$ → $5\theta = 110°$ → $\theta = 22°$

Type B3 — Verify an Identity for a Specific Angle

Solved Example 9

Q. If A = 60° and B = 30°, verify: $\cos(A-B) = \cos A\cos B + \sin A\sin B$

LHS: $\cos 30° = \dfrac{\sqrt{3}}{2}$

RHS: $\cos 60°\cos 30° + \sin 60°\sin 30° = \dfrac{1}{2}\cdot\dfrac{\sqrt{3}}{2} + \dfrac{\sqrt{3}}{2}\cdot\dfrac{1}{2} = \dfrac{\sqrt{3}}{4}+\dfrac{\sqrt{3}}{4} = \dfrac{\sqrt{3}}{2}$ ✓

Type B4 — Solve Quadratic Equations in Trig Ratios

Solved Example 10 (ML Aggarwal)

Q. Find acute θ: $2\cos^2\theta + \sin\theta - 2 = 0$

$2(1-\sin^2\theta) + \sin\theta - 2 = 0$

$2 - 2\sin^2\theta + \sin\theta - 2 = 0$

$-2\sin^2\theta + \sin\theta = 0$ → $\sin\theta(-2\sin\theta + 1) = 0$

$\sin\theta = 0$ (rejected for acute) or $\sin\theta = 1/2$ → $\theta = 30°$

Type B5 — Conditional Value Problem (Given Angle Equation)

Solved Example 11

Q. If $\tan(A+B) = \sqrt{3}$ and $\tan(A-B) = \dfrac{1}{\sqrt{3}}$, find A and B.

$A+B = 60°$ and $A-B = 30°$

Adding: $2A = 90°$ → $A = 45°$. Then $B = 15°$.

Part C: Trigonometric Identities — Complete Reference

3. Three Fundamental Pythagorean Identities + All Derived Forms

Identity 1: $\sin^2\theta + \cos^2\theta = 1$  →  $\sin^2\theta = 1-\cos^2\theta$  |  $\cos^2\theta = 1-\sin^2\theta$
Identity 2: $\sec^2\theta - \tan^2\theta = 1$  →  $\sec^2\theta = 1+\tan^2\theta$  |  $(\sec\theta-\tan\theta)(\sec\theta+\tan\theta)=1$
Identity 3: $\csc^2\theta - \cot^2\theta = 1$  →  $\csc^2\theta = 1+\cot^2\theta$  |  $(\csc\theta-\cot\theta)(\csc\theta+\cot\theta)=1$

Part D: Proving Identities — All 10 Types

Master Strategy
  1. Work on ONE side only (usually the complex side).
  2. Convert to sin & cos if stuck.
  3. Use LCM, factoring, conjugates, $a^2-b^2$, $a^3\pm b^3$ algebra.
  4. Replace $\sin^2+\cos^2$ with 1, $\sec^2-\tan^2$ with 1, etc.
  5. Write "LHS = … = RHS ✓" at the end.

Type P1 — Direct Substitution Using Pythagorean Identities

Solved Example 12

Q. Prove: $\dfrac{1+\tan^2\theta}{1+\cot^2\theta} = \tan^2\theta$

LHS $= \dfrac{\sec^2\theta}{\csc^2\theta} = \dfrac{1/\cos^2\theta}{1/\sin^2\theta} = \dfrac{\sin^2\theta}{\cos^2\theta} = \tan^2\theta = $ RHS ✓

Type P2 — LCM / Combining Fractions

Solved Example 13

Q. Prove: $\dfrac{\sin\theta}{1+\cos\theta} + \dfrac{1+\cos\theta}{\sin\theta} = 2\csc\theta$

LHS $= \dfrac{\sin^2\theta + (1+\cos\theta)^2}{\sin\theta(1+\cos\theta)} = \dfrac{\sin^2\theta+1+2\cos\theta+\cos^2\theta}{\sin\theta(1+\cos\theta)} = \dfrac{2+2\cos\theta}{\sin\theta(1+\cos\theta)} = \dfrac{2}{\sin\theta} = 2\csc\theta$ ✓

Type P3 — Conjugate Multiplication (Most Important!)

Solved Example 14

Q. Prove: $\dfrac{1+\sin\theta}{1-\sin\theta} = (\sec\theta+\tan\theta)^2$

RHS $= \left(\dfrac{1+\sin\theta}{\cos\theta}\right)^2 = \dfrac{(1+\sin\theta)^2}{\cos^2\theta} = \dfrac{(1+\sin\theta)^2}{(1-\sin\theta)(1+\sin\theta)} = \dfrac{1+\sin\theta}{1-\sin\theta} = $ LHS ✓

Solved Example 15 — Conjugate Trick

Q. Prove: $\dfrac{1}{\sec\theta-\tan\theta} = \sec\theta+\tan\theta$

LHS: Multiply by $\dfrac{\sec\theta+\tan\theta}{\sec\theta+\tan\theta}$: $= \dfrac{\sec\theta+\tan\theta}{\sec^2\theta-\tan^2\theta} = \dfrac{\sec\theta+\tan\theta}{1} = \sec\theta+\tan\theta = $ RHS ✓

Type P4 — $a^3 \pm b^3$ Factoring

Solved Example 16

Q. Prove: $\dfrac{\sin^3\theta+\cos^3\theta}{\sin\theta+\cos\theta} = 1 - \sin\theta\cos\theta$

$a^3+b^3 = (a+b)(a^2-ab+b^2)$

LHS $= \dfrac{(\sin\theta+\cos\theta)(\sin^2\theta-\sin\theta\cos\theta+\cos^2\theta)}{\sin\theta+\cos\theta} = 1 - \sin\theta\cos\theta = $ RHS ✓

Type P5 — $(a-b)(a+b) = a^2 - b^2$ Identity

Solved Example 17

Q. Prove: $(\sin A + \csc A)^2 + (\cos A + \sec A)^2 = 7 + \tan^2 A + \cot^2 A$

LHS $= \sin^2 A + 2 + \csc^2 A + \cos^2 A + 2 + \sec^2 A$

$= (\sin^2 A + \cos^2 A) + 4 + \csc^2 A + \sec^2 A$

$= 1 + 4 + (1+\cot^2 A) + (1+\tan^2 A) = 7 + \tan^2 A + \cot^2 A = $ RHS ✓

Type P6 — Rationalising Square Root Expressions

Solved Example 18

Q. Prove: $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} = \sec\theta + \tan\theta$

Multiply inside by $\dfrac{1+\sin\theta}{1+\sin\theta}$:

$= \sqrt{\dfrac{(1+\sin\theta)^2}{1-\sin^2\theta}} = \sqrt{\dfrac{(1+\sin\theta)^2}{\cos^2\theta}} = \dfrac{1+\sin\theta}{\cos\theta} = \sec\theta + \tan\theta = $ RHS ✓

Solved Example 19

Q. Prove: $\sqrt{\dfrac{\sec\theta-1}{\sec\theta+1}} + \sqrt{\dfrac{\sec\theta+1}{\sec\theta-1}} = 2\csc\theta$

Let $\sqrt{\frac{\sec\theta-1}{\sec\theta+1}} = \frac{\sqrt{\sec\theta-1}}{\sqrt{\sec\theta+1}}$. Multiply both terms by common and combine:

LHS $= \dfrac{(\sec\theta-1)+(\sec\theta+1)}{\sqrt{\sec^2\theta-1}} = \dfrac{2\sec\theta}{\tan\theta} = \dfrac{2}{\sin\theta} = 2\csc\theta = $ RHS ✓

Type P7 — Complex Expression: Convert Everything to sin & cos

Solved Example 20 (ICSE Board 2023)

Q. Prove: $\dfrac{\tan A}{1-\cot A} + \dfrac{\cot A}{1-\tan A} = 1 + \sec A\cdot\csc A$

$= \dfrac{\frac{\sin A}{\cos A}}{1-\frac{\cos A}{\sin A}} + \dfrac{\frac{\cos A}{\sin A}}{1-\frac{\sin A}{\cos A}} = \dfrac{\sin^2 A}{\cos A(\sin A-\cos A)} - \dfrac{\cos^2 A}{\sin A(\sin A-\cos A)}$

$= \dfrac{\sin^3 A - \cos^3 A}{\sin A\cos A(\sin A-\cos A)} = \dfrac{(\sin A-\cos A)(1+\sin A\cos A)}{\sin A\cos A(\sin A-\cos A)} = 1 + \sec A\csc A = $ RHS ✓

Type P8 — Proving Using $(a+b)^2$ and $(a-b)^2$ Expansion

Solved Example 21

Q. Prove: $\sin^4\theta - \cos^4\theta = 2\sin^2\theta - 1$

LHS $= (\sin^2\theta+\cos^2\theta)(\sin^2\theta-\cos^2\theta) = 1\cdot(\sin^2\theta - \cos^2\theta)$

$= \sin^2\theta - (1-\sin^2\theta) = 2\sin^2\theta - 1 = $ RHS ✓

Type P9 — Proving by Converting LHS to RHS Using Multiple Steps

Solved Example 22

Q. Prove: $\dfrac{\cos\theta}{1-\tan\theta} + \dfrac{\sin\theta}{1-\cot\theta} = \sin\theta + \cos\theta$

$\dfrac{\cos\theta}{1-\frac{\sin\theta}{\cos\theta}} + \dfrac{\sin\theta}{1-\frac{\cos\theta}{\sin\theta}} = \dfrac{\cos^2\theta}{\cos\theta-\sin\theta} + \dfrac{\sin^2\theta}{\sin\theta-\cos\theta}$

$= \dfrac{\cos^2\theta - \sin^2\theta}{\cos\theta-\sin\theta} = \dfrac{(\cos\theta+\sin\theta)(\cos\theta-\sin\theta)}{\cos\theta-\sin\theta} = \cos\theta + \sin\theta = $ RHS ✓

Type P10 — Proving Using Both Sides (Symmetric Approach)

Solved Example 23

Q. Prove: $(1+\cot A - \csc A)(1+\tan A + \sec A) = 2$

$= \left(\dfrac{\sin A + \cos A - 1}{\sin A}\right)\left(\dfrac{\cos A + \sin A + 1}{\cos A}\right)$

$= \dfrac{(\sin A+\cos A)^2 - 1^2}{\sin A\cos A} = \dfrac{\sin^2 A + 2\sin A\cos A + \cos^2 A - 1}{\sin A\cos A}$

$= \dfrac{1 + 2\sin A\cos A - 1}{\sin A\cos A} = \dfrac{2\sin A\cos A}{\sin A\cos A} = 2 = $ RHS ✓

Part E: Complementary Angles — All Types

4. The Six Complementary Relations

$$\sin(90°-\theta)=\cos\theta \quad \cos(90°-\theta)=\sin\theta$$ $$\tan(90°-\theta)=\cot\theta \quad \cot(90°-\theta)=\tan\theta$$ $$\sec(90°-\theta)=\csc\theta \quad \csc(90°-\theta)=\sec\theta$$

Type C1 — Simplify Expression to a Number

Solved Example 24

Q. Evaluate: $\dfrac{\sin 18°}{\cos 72°} + \dfrac{\sqrt{3}\tan 10°\tan 30°\tan 80°}{2}$

$\cos 72° = \sin(90°-72°) = \sin 18°$ → first term = 1

$\tan 80° = \cot 10°$ → $\tan 10°\tan 80° = \tan 10°\cot 10° = 1$

$= 1 + \dfrac{\sqrt{3}\cdot 1\cdot(1/\sqrt{3})}{2} = 1 + \dfrac{1}{2} = \dfrac{3}{2}$

Type C2 — Product of Tan Angles = 1

Solved Example 25

Q. Show that $\tan 1°\tan 2°\tan 3°\cdots\tan 89° = 1$

Pair $\tan k° \cdot \tan(90°-k°) = \tan k° \cdot \cot k° = 1$ for $k = 1,2,...,44$. Middle term $\tan 45° = 1$.

Product = $1 \times 1 \times \cdots \times 1 = 1$ ✓

Type C3 — Sum of Squared Angles = 1

Solved Example 26

Q. Evaluate (without tables): $\sin^2 20° + \sin^2 70°$

$\sin 70° = \sin(90°-20°) = \cos 20°$

$= \sin^2 20° + \cos^2 20° = 1$

Type C4 — Complementary Angle Equations to Find θ

Solved Example 27

Q. Find θ if $\sec(2\theta+10°) = \csc(3\theta-15°)$.

Since sec α = csc(90°−α): $2\theta+10° + 3\theta-15° = 90°$ → $5\theta = 95°$ → $\theta = 19°$

Type C5 — Proving Using Complementary Angles

Solved Example 28

Q. Prove: $\dfrac{\cos(90°-\theta)}{1+\sin(90°-\theta)} + \dfrac{1+\sin(90°-\theta)}{\cos(90°-\theta)} = 2\csc\theta$

Replace: $\cos(90°-\theta)=\sin\theta$, $\sin(90°-\theta)=\cos\theta$

$= \dfrac{\sin\theta}{1+\cos\theta}+\dfrac{1+\cos\theta}{\sin\theta} = \dfrac{\sin^2\theta+(1+\cos\theta)^2}{\sin\theta(1+\cos\theta)} = \dfrac{2(1+\cos\theta)}{\sin\theta(1+\cos\theta)} = \dfrac{2}{\sin\theta} = 2\csc\theta$ ✓

Part F: Conditional Proving — All Types

Type F1 — If [Condition], Prove [Expression]

Solved Example 29

Q. If $\cos\theta - \sin\theta = \sqrt{2}\sin\theta$, prove that $\cos\theta + \sin\theta = \sqrt{2}\cos\theta$.

Given: $\cos\theta = \sin\theta(1+\sqrt{2})$ → $\sin\theta = \dfrac{\cos\theta}{1+\sqrt{2}} = \dfrac{\cos\theta(1-\sqrt{2})}{(1+\sqrt{2})(1-\sqrt{2})} = \cos\theta(\sqrt{2}-1)$

LHS: $\cos\theta + \sin\theta = \cos\theta + \cos\theta(\sqrt{2}-1) = \cos\theta\cdot\sqrt{2} = \sqrt{2}\cos\theta$ = RHS ✓

Type F2 — Square and Add (Classic ICSE Type)

Solved Example 30

Q. If $a\cos\theta + b\sin\theta = m$ and $a\sin\theta - b\cos\theta = n$, prove that $a^2 + b^2 = m^2 + n^2$.

$m^2 + n^2 = (a\cos\theta+b\sin\theta)^2 + (a\sin\theta-b\cos\theta)^2$

$= a^2\cos^2\theta+2ab\sin\theta\cos\theta+b^2\sin^2\theta + a^2\sin^2\theta-2ab\sin\theta\cos\theta+b^2\cos^2\theta$

$= a^2(\sin^2\theta+\cos^2\theta) + b^2(\sin^2\theta+\cos^2\theta) = a^2+b^2$ ✓

Type F3 — Eliminate θ Between Two Equations

Solved Example 31 (ML Aggarwal)

Q. If $x = a\sec\theta$ and $y = b\tan\theta$, eliminate θ to prove: $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$

$\sec\theta = x/a$ and $\tan\theta = y/b$

Using $\sec^2\theta - \tan^2\theta = 1$: $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ ✓

Solved Example 32

Q. If $x = r\sin A\cos C$, $y = r\sin A\sin C$, $z = r\cos A$, prove $r^2 = x^2+y^2+z^2$.

$x^2+y^2 = r^2\sin^2 A(\cos^2 C+\sin^2 C) = r^2\sin^2 A$

$x^2+y^2+z^2 = r^2\sin^2 A + r^2\cos^2 A = r^2$ ✓

Type F4 — If Given sin + cos = k, Find Other Expressions

Solved Example 33

Q. If $\sin\theta + \cos\theta = p$ and $\sec\theta + \csc\theta = q$, show that $q(p^2-1) = 2p$.

$p^2 = (\sin\theta+\cos\theta)^2 = 1 + 2\sin\theta\cos\theta$ → $\sin\theta\cos\theta = \dfrac{p^2-1}{2}$

$q = \sec\theta+\csc\theta = \dfrac{\cos\theta+\sin\theta}{\sin\theta\cos\theta} = \dfrac{p}{(p^2-1)/2} = \dfrac{2p}{p^2-1}$

→ $q(p^2-1) = 2p$ ✓

Type F5 — If Given sec − tan = k, Find Other Expressions

Solved Example 34

Q. If $\sec\theta - \tan\theta = k$, prove that $\sin\theta = \dfrac{1-k^2}{1+k^2}$.

We know $(\sec\theta-\tan\theta)(\sec\theta+\tan\theta) = 1$ → $\sec\theta+\tan\theta = 1/k$

Adding: $2\sec\theta = k + 1/k = (k^2+1)/k$ → $\sec\theta = (k^2+1)/(2k)$

Subtracting: $2\tan\theta = 1/k - k = (1-k^2)/k$ → $\tan\theta = (1-k^2)/(2k)$

$\sin\theta = \dfrac{\tan\theta}{\sec\theta} = \dfrac{(1-k^2)/(2k)}{(1+k^2)/(2k)} = \dfrac{1-k^2}{1+k^2}$ ✓

Type F6 — Conditional: Given sin θ = k, Express in algebraic form

Solved Example 35

Q. If $\tan A + \sin A = m$ and $\tan A - \sin A = n$, show that $m^2 - n^2 = 4\sqrt{mn}$.

$m^2 - n^2 = (m+n)(m-n) = (2\tan A)(2\sin A) = 4\sin A\tan A$

$mn = (\tan A+\sin A)(\tan A-\sin A) = \tan^2 A - \sin^2 A = \dfrac{\sin^2 A}{\cos^2 A} - \sin^2 A = \dfrac{\sin^2 A(1-\cos^2 A)}{\cos^2 A} = \sin^2 A\tan^2 A$

$\sqrt{mn} = \sin A\tan A$ → $4\sqrt{mn} = 4\sin A\tan A = m^2-n^2$ ✓

Practice — Conditional Proving
Q1 (F1). If $\sin\theta + \sin^2\theta = 1$, prove $\cos^2\theta + \cos^4\theta = 1$  [3M]
Hint: sinθ = 1 − sin²θ = cos²θ. Then sin²θ = cos⁴θ. cos²θ + cos⁴θ = cos²θ + sin²θ = 1 ✓
Q2 (F2). If $x = p\sec\theta + q\tan\theta$ and $y = p\tan\theta + q\sec\theta$, prove $x^2-y^2 = p^2-q^2$  [4M]
Hint: x²−y² = (p²sec²θ+2pqsecθtanθ+q²tan²θ) − (p²tan²θ+2pqsecθtanθ+q²sec²θ) = p²(sec²−tan²) − q²(sec²−tan²) = p²−q² ✓
Q3 (F3). If $x = a\cos\theta - b\sin\theta$ and $y = a\sin\theta + b\cos\theta$, prove $x^2+y^2 = a^2+b^2$  [3M]
Hint: Square and add. Cross terms cancel. Use sin²+cos²=1.
Q4 (F5). If $\csc\theta - \cot\theta = \frac{1}{3}$, find $\csc\theta$ and $\cot\theta$  [3M]
Hint: cscθ+cotθ = 1/(cscθ−cotθ) = 3. Adding: 2cscθ = 1/3+3 = 10/3 → cscθ = 5/3. cotθ = 5/3 − 1/3 = 4/3.
Q5 (F4). If $\tan\theta + \dfrac{1}{\tan\theta} = 2$, find $\tan^2\theta + \dfrac{1}{\tan^2\theta}$  [3M]
Hint: Square given: tan²θ + 2 + 1/tan²θ = 4 → tan²θ + 1/tan²θ = 2
Q6 (F6). If $\tan A : \tan B = p:q$, prove $\dfrac{\sin(A+B)}{\sin(A-B)} = \dfrac{p+q}{p-q}$  [4M]
Hint: Write sin(A+B) = sinAcosB+cosAsinB, sin(A-B)=sinAcosB−cosAsinB. Divide by cosAcosB. Then numerator/denom = (tanA+tanB)/(tanA−tanB) = (p+q)/(p−q) ✓

Part G: Heights and Distances — All 8 Problem Types

Key Definitions

Angle of Elevation: Angle between horizontal and line of sight when observer looks UP.

Angle of Depression: Angle between horizontal and line of sight when observer looks DOWN.

Key: Angle of elevation from A to B = Angle of depression from B to A (alternate interior angles).

$$\tan\theta = \frac{\text{Height}}{\text{Horizontal Distance}} \qquad \text{Height} = \text{Distance} \times \tan\theta \qquad \text{Distance} = \frac{\text{Height}}{\tan\theta}$$

Type H1 — Single Angle of Elevation — Find Height

Solved Example 36

Q. A tower stands vertically on the ground. From a point on the ground, which is 15 m away from the foot of the tower, the angle of elevation of the top is 60°. Find the height of the tower.

$\tan 60° = h/15$ → $h = 15\sqrt{3} \approx \mathbf{25.98\ m}$

Type H2 — Single Angle of Depression — Find Distance

Solved Example 37

Q. From the top of a building 100 m high, the angle of depression of a car is 30°. Find the distance of the car from the building.

Angle of depression = 30° ⟹ angle of elevation from car to top = 30°

$\tan 30° = 100/d$ → $d = 100\sqrt{3} \approx \mathbf{173.2\ m}$

Type H3 — Observer Moves, Two Angles (Classic)

Solved Example 38 (Most Common ICSE Type)

Q. From a point on the ground, the angle of elevation of the top of a tree is 30°. The observer walks 20 m towards the tree and the angle becomes 60°. Find the height of the tree.

Setup: height = h, initial distance = x

Eq 1: $\tan 30° = h/x$ → $x = h\sqrt{3}$

Eq 2: $\tan 60° = h/(x-20)$ → $x-20 = h/\sqrt{3}$

Substituting: $h\sqrt{3} - 20 = h/\sqrt{3}$ → $3h - 20\sqrt{3} = h$ → $2h = 20\sqrt{3}$ → $h = 10\sqrt{3} \approx \mathbf{17.32\ m}$

Type H4 — Tower on Top of a Building

Solved Example 39 (ICSE Board 2022)

Q. From a point on the ground, the angles of elevation of the bottom and top of a transmission tower fixed at the top of a 20 m building are 45° and 60°. Find the height of the tower.

Let d = distance, h = tower height

Angle 45° to top of building: $\tan 45° = 20/d$ → $d = 20$ m

Angle 60° to top of tower: $\tan 60° = (20+h)/20$ → $20\sqrt{3} = 20+h$ → $h = 20(\sqrt{3}-1) \approx \mathbf{14.64\ m}$

Type H5 — Two Objects on Opposite Sides of a Tower

Solved Example 40

Q. From the top of a tower h m high, angles of depression of two objects on opposite sides are α and β. Prove that the distance between them is $h(\cot\alpha + \cot\beta)$.

$d_1 = h\cot\alpha$, $d_2 = h\cot\beta$. Total = $h(\cot\alpha+\cot\beta)$ ✓

Type H6 — Depression from Top of Building to Top and Bottom of Another

Solved Example 41

Q. From the top of a 50 m building, angles of depression to top and bottom of a tower are 45° and 60°. Find height of tower and horizontal distance.

Let h = tower height, d = horizontal distance

Depression 60° to base: $\tan 60° = 50/d$ → $d = \dfrac{50}{\sqrt{3}} = \dfrac{50\sqrt{3}}{3}$ m

Depression 45° to top: $\tan 45° = (50-h)/d$ → $50-h = d = \dfrac{50\sqrt{3}}{3}$

$h = 50 - \dfrac{50\sqrt{3}}{3} = \dfrac{50(3-\sqrt{3})}{3} \approx \mathbf{21.13\ m}$

Type H7 — Two Poles of Equal Height on Opposite Sides of Road

Solved Example 42

Q. Two poles of equal heights stand on either side of a 80 m wide road. From a point P between them on the road, angles of elevation of their tops are 60° and 30°. Find the height of the poles and position of P.

Let height = h, P is x m from pole 1 (angle 60°), (80-x) from pole 2 (angle 30°)

$\tan 60° = h/x$ → $h = x\sqrt{3}$   ...(1)

$\tan 30° = h/(80-x)$ → $h = (80-x)/\sqrt{3}$   ...(2)

From (1)&(2): $x\sqrt{3} = (80-x)/\sqrt{3}$ → $3x = 80-x$ → $x = 20$ m

$h = 20\sqrt{3} \approx \mathbf{34.64\ m}$. P is 20 m from first pole, 60 m from second.

Type H8 — Combined H&D (From Ship / Aeroplane / Cliff)

Solved Example 43

Q. A man standing on the deck of a ship, 10 m above the water level, observes the angle of elevation of the top of a hill as 60° and the angle of depression of the base of the hill as 30°. Find the distance of the hill from the ship and the height of the hill.

Elevation 60° to top: $\tan 60° = (H-10)/d$ → $H-10 = 10\sqrt{3}\cdot\sqrt{3} = 30$

$H = 40$ m. Distance of hill = $10\sqrt{3} \approx \mathbf{17.32\ m}$

Practice — Heights & Distances (All Types)
Q1 (H1). A kite is flying at a height of 60 m above the ground. The string attached to the kite is tied at the ground. If the string is 90 m long and makes an angle with the ground, find the angle.  [2M]
Ans: sin θ = 60/90 = 2/3. θ = sin⁻¹(2/3) ≈ 41.8°
Q2 (H2). A man is watching a TV tower. From a distance of 45 m, the angle of elevation to the top is 60°. The tower is standing on a building of height 15 m. Find the height of the tower.  [3M]
Ans: tan60° = (15+h)/45 → 45√3 = 15+h → h = 45√3−15 = 15(3√3−1) ≈ 62.9 m
Q3 (H3). The angle of elevation of a jet fighter from a point A on the ground is 60°. After 15 seconds, the angle becomes 30°. If the jet flies at a constant height of 1500√3 m, find the speed of the jet.  [4M]
Solution: At 60°: d₁ = 1500√3/tan60° = 1500 m. At 30°: d₂ = 1500√3/tan30° = 1500√3·√3 = 4500 m. Distance = 4500−1500 = 3000 m in 15s. Speed = 3000/15 = 200 m/s = 720 km/h
Q4 (H4). A tower AB is 20 m high, a flagstaff BC is fixed at its top. From a point P on the ground such that PC = 45 m, the angle of elevation of B is 45°. Find the angle of elevation of C from P.  [4M]
Hint: tan45°=20/d → d=20m. But PC=45m not 20m → re-read: from P, d=horizontal dist. tan∠P(C) = 20+BC/20. First find BC: PC²=d²+BC² using right triangle... Use: tanθ_C = (20+BC)/d = (20+BC)/20.
Q5 (H5). From the top of a tower of height 200 m, the angles of depression of two points P and Q on the ground on the same side of the tower are 45° and 60°. Find the distance between P and Q.  [4M]
Solution: d_P = 200/tan45° = 200 m. d_Q = 200/tan60° = 200/√3. PQ = 200 − 200/√3 = 200(1−1/√3) = 200(√3−1)/√3 ≈ 84.5 m
Q6 (H6). From a window 10 m above ground, the angles of depression of the foot and top of a building across a lane are 60° and 30° respectively. Find width of lane and height of building.  [4M]
Solution: Depression 60° to foot: d=10/tan60°=10/√3. Depression 30° to top: (10−h)/d=tan30°=1/√3 → 10−h = 10/3 → h=20/3≈6.67m. Width = 10/√3 ≈ 5.77 m. Height = 20/3 m
Q7 (H7). Two ships are sailing in the sea on either side of a lighthouse. The angles of depression of the two ships from the top of the lighthouse are 45° and 30° respectively. If the lighthouse is 100 m high, find the distance between the two ships.  [4M]
Solution: d₁=100cot45°=100m. d₂=100cot30°=100√3m. Distance = 100+100√3 = 100(1+√3) ≈ 273.2 m
Q8 (H8 HOTS). An aeroplane at altitude 3000 m passes vertically above another aeroplane. The angles of elevation of the two from the same point on the ground are 60° and 45°. Find the vertical distance between them.  [4M]
Solution: tan60°=3000/d → d=3000/√3=1000√3. tan45°=h₂/d → h₂=1000√3. Gap = 3000−1000√3 = 1000(3−√3) ≈ 1267.9 m

ICSE Board Exam Tips
  1. In proving: always work on ONE side only. Write "LHS = … = RHS ✓"
  2. In Heights & Distances: draw a diagram first — earns 1 mark even if calculation goes wrong.
  3. Do not cross-multiply in a proving question — use algebraic manipulation on one side.
  4. Leave final answers in surd form (e.g., 20√3 m) unless decimal asked.
  5. Rationalise all denominators — no √3 or √2 in denominator in final answer.
  6. Angle of depression = angle of elevation (alternate interior angles) — use this freely.
  7. tan 90° = ∞ (undefined) — never write a value for it.
  8. For "find acute angle" problems — your answer must be one of 0°, 30°, 45°, 60°, 90°.

HOTS — All Types
Q1. If $\sec\theta+\tan\theta=p$, prove $\sin\theta=\dfrac{p^2-1}{p^2+1}$  [4M]
Hint: secθ−tanθ=1/p. Add to get secθ=(p²+1)/2p, subtract to get tanθ=(p²−1)/2p. sinθ=tanθ/secθ=(p²−1)/(p²+1) ✓
Q2. Prove $\sqrt{\dfrac{1+\sin A}{1-\sin A}}+\sqrt{\dfrac{1-\sin A}{1+\sin A}}=2\sec A$  [4M]
Hint: First root = (1+sinA)/cosA, second root = (1−sinA)/cosA. Sum = 2/cosA = 2secA ✓
Q3. A vertical tower stands on a horizontal plane and is surmounted by a flagstaff of height h. From a point on the plane, angles of elevation of bottom and top of flagstaff are α and β. Prove tower height = $\dfrac{h\tan\alpha}{\tan\beta-\tan\alpha}$  [5M]
Solution: Let tower height=T, dist=d. tanα=T/d and tanβ=(T+h)/d. From first: d=T/tanα. Sub in second: T+h=Ttanβ/tanα → T(tanβ/tanα−1)=h → T=htanα/(tanβ−tanα) ✓
Q4. Prove $\dfrac{\cos^2\theta}{1-\tan\theta}+\dfrac{\sin^3\theta}{\sin\theta-\cos\theta}=1+\sin\theta\cos\theta$  [5M]
Hint: 1st term: cos³θ/(cosθ−sinθ). 2nd term: −sin³θ/(cosθ−sinθ). Combined: (cos³θ−sin³θ)/(cosθ−sinθ) = cos²θ+sinθcosθ+sin²θ = 1+sinθcosθ ✓
Q5. Eliminate θ from: $x = a\cos^3\theta$, $y = b\sin^3\theta$  [3M]
Solution: cosθ=(x/a)^(1/3), sinθ=(y/b)^(1/3). Use sin²θ+cos²θ=1: $(x/a)^{2/3}+(y/b)^{2/3}=1$ ✓
