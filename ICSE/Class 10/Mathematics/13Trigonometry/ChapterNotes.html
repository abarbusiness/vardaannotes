Chapter 13: Trigonometry

Trigonometry is the study of the relationship between the sides and angles of a right-angled triangle. In ICSE Class 10, this chapter covers six trigonometric ratios, fundamental identities (Pythagorean, quotient, reciprocal), complementary angle relations, proving of identities, and practical applications in heights & distances problems.

Part A: Trigonometric Ratios

1. The Right-Angled Triangle

In a right-angled triangle, for a given angle θ at vertex A, the three sides are named with respect to θ:

  • Opposite (Perpendicular, P): The side opposite to angle θ.
  • Adjacent (Base, B): The side adjacent to angle θ (not the hypotenuse).
  • Hypotenuse (H): The longest side, always opposite the right angle.

Memory Tricks

SOH – CAH – TOA: Sin = Opposite/Hypotenuse; Cos = Adjacent/Hypotenuse; Tan = Opposite/Adjacent

3. Finding All Ratios from One Given Ratio

Use Pythagoras Theorem: $H^2 = P^2 + B^2$ to find the missing side, then list all six ratios.

Practice Problems — Finding Ratios
Q1. If sin θ = 3/5, find all other trigonometric ratios.
Solution:
P = 3, H = 5  →  $B = \sqrt{H^2-P^2} = \sqrt{25-9} = 4$
$\cos\theta = \frac{4}{5}$  |  $\tan\theta = \frac{3}{4}$  |  $\csc\theta = \frac{5}{3}$  |  $\sec\theta = \frac{5}{4}$  |  $\cot\theta = \frac{4}{3}$
Ans: See values above.
Q2. If cos θ = 12/13, find all other trigonometric ratios.
Solution:
B = 12, H = 13  →  $P = \sqrt{169-144} = 5$
$\sin\theta = \frac{5}{13}$  |  $\tan\theta = \frac{5}{12}$  |  $\csc\theta = \frac{13}{5}$  |  $\sec\theta = \frac{13}{12}$  |  $\cot\theta = \frac{12}{5}$
Ans: See values above.
Q3 (ICSE Type). If 15 cot A = 8, find sin A and sec A.
Solution:
cot A = 8/15  →  B = 8, P = 15, $H = \sqrt{64+225} = \sqrt{289} = 17$
$\sin A = \frac{15}{17}$  |  $\sec A = \frac{17}{8}$
Ans: sin A = 15/17, sec A = 17/8
Q4. If tan θ = 1/√3, find the value of $\dfrac{\sin\theta + \cos\theta}{\sec\theta + \csc\theta}$.
Solution:
tan θ = 1/√3 → P=1, B=√3, H=2. sin=1/2, cos=√3/2, sec=2/√3, csc=2
$= \dfrac{\frac{1}{2}+\frac{\sqrt{3}}{2}}{\frac{2}{\sqrt{3}}+2} = \dfrac{\frac{1+\sqrt{3}}{2}}{\frac{2(1+\sqrt{3})}{\sqrt{3}}} = \dfrac{\sqrt{3}}{4}$
Ans: √3/4

Q3 (ICSE type). Verify that $\sin 2\theta = 2\sin\theta\cos\theta$ for θ = 30°.
Solution:
LHS: $\sin 60° = \frac{\sqrt{3}}{2}$
RHS: $2 \times \frac{1}{2} \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{2}$

$= \frac{3/4}{1/4} = 3$

Part C: Trigonometric Identities

5. Three Fundamental Pythagorean Identities

Identity 1: $\quad\sin^2\theta + \cos^2\theta = 1$
Identity 2: $\quad 1 + \tan^2\theta = \sec^2\theta \quad\Rightarrow\quad \sec^2\theta - \tan^2\theta = 1$
Identity 3: $\quad 1 + \cot^2\theta = \csc^2\theta \quad\Rightarrow\quad \csc^2\theta - \cot^2\theta = 1$

6. All Derived Rearrangements

FromDerived Forms
Identity 1
$\sin^2\theta + \cos^2\theta = 1$		$\sin^2\theta = 1 - \cos^2\theta$
$\cos^2\theta = 1 - \sin^2\theta$
$(1-\sin\theta)(1+\sin\theta) = \cos^2\theta$
$(1-\cos\theta)(1+\cos\theta) = \sin^2\theta$
Identity 2
$\sec^2\theta - \tan^2\theta = 1$		$\tan^2\theta = \sec^2\theta - 1$
$(\sec\theta - \tan\theta)(\sec\theta + \tan\theta) = 1$
Identity 3
$\csc^2\theta - \cot^2\theta = 1$		$\cot^2\theta = \csc^2\theta - 1$
$(\csc\theta - \cot\theta)(\csc\theta + \cot\theta) = 1$
⭐ Gold Tip — Conjugate Pair Trick

Whenever you see $(\sec\theta - \tan\theta)$, its conjugate is $(\sec\theta + \tan\theta)$, and their product equals 1. Same for $(\csc\theta - \cot\theta)$.

This is the single most powerful technique in ICSE Trigonometry proving questions!

Part D: Proving Trigonometric Identities

7. Master Strategy for Proving

Step-by-Step Method
  1. Work on one side only — usually the more complex side. Never change both sides simultaneously.
  2. Convert everything to sin θ and cos θ if stuck.
  3. Use algebraic techniques: LCM, factoring, expanding.
  4. Apply Pythagorean identities to replace $\sin^2+\cos^2$ with 1.
  5. Look for conjugate pairs to multiply and simplify.
  6. End with: LHS = … = … = RHS ✓

8. Type A — Direct Identity Substitution

Solved Example 1

Q. Prove: $\sin^4\theta + \cos^4\theta = 1 - 2\sin^2\theta\cos^2\theta$

LHS

$= (\sin^2\theta + \cos^2\theta)^2 - 2\sin^2\theta\cos^2\theta$    [since $(a+b)^2 - 2ab = a^2+b^2$]

$= 1 - 2\sin^2\theta\cos^2\theta = \text{RHS}$ ✓

9. Type B — LCM / Fraction Approach

Solved Example 2

Q. Prove: $\dfrac{\sin\theta}{1-\cos\theta} + \dfrac{1-\cos\theta}{\sin\theta} = 2\csc\theta$

LHS — Take LCM

$= \dfrac{\sin^2\theta + (1-\cos\theta)^2}{\sin\theta(1-\cos\theta)} = \dfrac{\sin^2\theta + 1 - 2\cos\theta + \cos^2\theta}{\sin\theta(1-\cos\theta)}$

$= \dfrac{2 - 2\cos\theta}{\sin\theta(1-\cos\theta)} = \dfrac{2(1-\cos\theta)}{\sin\theta(1-\cos\theta)} = \dfrac{2}{\sin\theta} = 2\csc\theta = \text{RHS}$ ✓

10. Type C — Conjugate Multiplication

Solved Example 3 (Very Common in ICSE)

Q. Prove: $(\sec\theta - \tan\theta)^2 = \dfrac{1-\sin\theta}{1+\sin\theta}$

LHS — Expand in sin/cos

$= \left(\dfrac{1-\sin\theta}{\cos\theta}\right)^2 = \dfrac{(1-\sin\theta)^2}{\cos^2\theta} = \dfrac{(1-\sin\theta)^2}{(1-\sin\theta)(1+\sin\theta)} = \dfrac{1-\sin\theta}{1+\sin\theta} = \text{RHS}$ ✓

11. Type D — Factoring using $a^3 \pm b^3$

Solved Example 4

Q. Prove: $\dfrac{\sin^3\theta + \cos^3\theta}{\sin\theta + \cos\theta} + \sin\theta\cos\theta = 1$

LHS — Use $a^3+b^3=(a+b)(a^2-ab+b^2)$

$= \dfrac{(\sin\theta+\cos\theta)(1 - \sin\theta\cos\theta)}{\sin\theta+\cos\theta} + \sin\theta\cos\theta$

$= (1 - \sin\theta\cos\theta) + \sin\theta\cos\theta = 1 = \text{RHS}$ ✓

12. Type E — The Classic ICSE Board Proving Question

Solved Example 5 (ICSE Board 2023)

Q. Prove: $\dfrac{\tan A}{1-\cot A} + \dfrac{\cot A}{1-\tan A} = 1 + \sec A\cdot\csc A$

Step 1 — Convert to sin & cos

$= \dfrac{\sin^2 A}{\cos A(\sin A - \cos A)} - \dfrac{\cos^2 A}{\sin A(\sin A - \cos A)}$

Step 2 — Take LCM

$= \dfrac{\sin^3 A - \cos^3 A}{\sin A\cos A(\sin A - \cos A)} = \dfrac{(\sin A-\cos A)(1+\sin A\cos A)}{\sin A\cos A(\sin A-\cos A)}$

$= \dfrac{1+\sin A\cos A}{\sin A\cos A} = 1 + \dfrac{1}{\sin A\cos A} = 1 + \sec A\csc A = \text{RHS}$ ✓

Practice Problems — Proving Identities
Q1. Prove: $\dfrac{\cos A}{1+\sin A} + \dfrac{1+\sin A}{\cos A} = 2\sec A$   [3M]
Hint: Take LCM → numerator becomes $\cos^2 A + (1+\sin A)^2 = 2(1+\sin A)$ → cancel → $2/\cos A$ ✓
Q2. Prove: $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} = \sec\theta + \tan\theta$   [3M]
Hint: Multiply inside root by $(1+\sin\theta)/(1+\sin\theta)$ → $\frac{(1+\sin\theta)^2}{\cos^2\theta}$ → take root → $(1+\sin\theta)/\cos\theta = \sec\theta + \tan\theta$ ✓
Q3. Prove: $(\sin\theta + \csc\theta)^2 + (\cos\theta + \sec\theta)^2 = \tan^2\theta + \cot^2\theta + 7$   [4M]
Hint: Expand LHS. Use $\sin^2+\cos^2=1$, $\sec^2=1+\tan^2$, $\csc^2=1+\cot^2$. LHS = $2+\csc^2\theta+2+\sec^2\theta = 4 + (1+\cot^2)+(1+\tan^2) = \tan^2\theta+\cot^2\theta+6$... re-verify: $= 7 + \tan^2\theta + \cot^2\theta$ ✓
Q4. Prove: $\dfrac{1}{\sec\theta-\tan\theta} - \dfrac{1}{\cos\theta} = \dfrac{1}{\cos\theta} - \dfrac{1}{\sec\theta+\tan\theta}$   [3M]
Hint: LHS: $\frac{1}{\sec\theta-\tan\theta} = \sec\theta+\tan\theta$ (conjugate trick). Rearrange and show both sides equal $2\tan\theta$.
Q5. If sin θ − cos θ = 0, find the value of $\sin^4\theta + \cos^4\theta$.   [3M]
Solution:
sin θ = cos θ  →  $\sin\theta = \cos\theta = \frac{1}{\sqrt{2}}$
$\sin^4\theta + \cos^4\theta = 2\times\left(\frac{1}{\sqrt{2}}\right)^4 = 2\times\frac{1}{4} = \frac{1}{2}$
Ans: 1/2
Q6. Prove: $\dfrac{\tan^2\theta}{(\sec\theta-1)^2} = \dfrac{1+\cos\theta}{1-\cos\theta}$   [3M]
Hint: $\tan^2\theta = \sec^2\theta-1 = (\sec\theta-1)(\sec\theta+1)$. Substitute and simplify. Convert sec to 1/cos.

Part E: Complementary Angles (90° − θ)

13. All Six Relations

$$\sin(90°-\theta) = \cos\theta \qquad \cos(90°-\theta) = \sin\theta$$ $$\tan(90°-\theta) = \cot\theta \qquad \cot(90°-\theta) = \tan\theta$$ $$\sec(90°-\theta) = \csc\theta \qquad \csc(90°-\theta) = \sec\theta$$
Rule

"Co" functions pair together: sin ↔ cos, tan ↔ cot, sec ↔ csc.

The angle and its complement always add to 90°. Very commonly used to simplify expressions.

Solved Example 6

Q. Evaluate: $\dfrac{\sin 35°}{\cos 55°} + \dfrac{\cos 25°}{\sin 65°}$

$\cos 55° = \sin(90°-55°) = \sin 35°$  and  $\sin 65° = \cos(90°-65°) = \cos 25°$

$= \dfrac{\sin 35°}{\sin 35°} + \dfrac{\cos 25°}{\cos 25°} = 1 + 1 = \mathbf{2}$

Practice Problems — Complementary Angles
Q1. Evaluate (without tables): $\sin^2 22° + \sin^2 68° + \cos^2 20°\cdot\cos^2 70°$   [3M]
Solution:
$\sin 68° = \cos 22°$ → $\sin^2 22° + \cos^2 22° = 1$
$\cos 70° = \sin 20°$ → $\cos^2 20°\cdot\sin^2 20°$ (small positive value, not directly 1). Recalculate: the last term ≈ 0. Full expression ≈ 1. But careful — the term $\cos^2 20°\cdot\cos^2 70°$ is not a standard identity. Answer: 1 (since last term = 0 only if cos 70° = sin 20° and product ≠ 1).
Ans: 1 (first two terms complete the identity; last term is extra)
Q2. Show that: $\tan 1° \cdot \tan 2° \cdot \tan 3° \cdots \tan 89° = 1$   [3M]
Solution:
Pair each angle: $\tan k° \cdot \tan(90°-k°) = \tan k° \cdot \cot k° = 1$ for each pair.
The middle term $\tan 45° = 1$. So entire product = $1 \times 1 \times \cdots \times 1 = 1$ ✓
Q3. Prove: $\sin(90°-\theta)\sin\theta - \cos(90°-\theta)\cos\theta = 0$   [2M]
Solution:
$= \cos\theta\cdot\sin\theta - \sin\theta\cdot\cos\theta = 0$ ✓

Part F: Proving When a Condition is Given

14. Strategy

Use the given condition to express one trig ratio in terms of another, then substitute into the expression to be proved. Squaring the given condition is often needed.

Solved Example 7

Q. If $a\cos\theta + b\sin\theta = c$, prove that $a\sin\theta - b\cos\theta = \pm\sqrt{a^2+b^2-c^2}$.

Let x = a sin θ − b cos θ. Add squares:

$(a\cos\theta+b\sin\theta)^2 + (a\sin\theta-b\cos\theta)^2 = a^2+b^2$

$c^2 + x^2 = a^2+b^2$  →  $x = \pm\sqrt{a^2+b^2-c^2}$ ✓

Practice Problems — Conditional Proving
Q1. If $\tan\theta = \dfrac{a}{b}$, prove that $\dfrac{a\sin\theta - b\cos\theta}{a\sin\theta + b\cos\theta} = \dfrac{a^2-b^2}{a^2+b^2}$   [4M]
Hint: Divide numerator and denominator by cos θ → express in terms of tan θ → substitute tan θ = a/b → simplify.
Q2. If $\sin\theta + \sin^2\theta = 1$, prove that $\cos^2\theta + \cos^4\theta = 1$.   [3M]
Solution:
Given: sin θ = 1 − sin²θ = cos²θ. Therefore $\sin^2\theta = \cos^4\theta$.
LHS: $\cos^2\theta + \cos^4\theta = \cos^2\theta + \sin^2\theta = 1 = \text{RHS}$ ✓
Q3. If $\csc\theta - \cot\theta = k$, prove that $\cos\theta = \dfrac{1-k^2}{1+k^2}$   [4M]
Hint: We know $(\csc\theta-\cot\theta)(\csc\theta+\cot\theta) = 1$, so $\csc\theta+\cot\theta = 1/k$. Add/subtract to find csc θ and cot θ individually, then use $\cos\theta = \cot\theta/\csc\theta$.

Part G: Heights and Distances

15. Key Definitions

Definitions

Angle of Elevation: The angle between the horizontal line and the line of sight when an observer looks UP at an object.

Angle of Depression: The angle between the horizontal line and the line of sight when an observer looks DOWN at an object.

Key Property: Angle of elevation from A to B = Angle of depression from B to A (alternate interior angles, since horizontal lines are parallel).

$$\tan\theta = \frac{\text{Height (Perpendicular)}}{\text{Distance (Base)}} \qquad\Rightarrow\qquad \text{Height} = \text{Distance} \times \tan\theta$$

16. Problem Types with Solved Examples

Type 1 — Single Angle, Find Height

Q. From a point 40 m away from a tower, angle of elevation = 60°. Find height.

$\tan 60° = h/40$  →  $h = 40\sqrt{3} \approx \mathbf{69.28\ m}$

Type 2 — Two Angles, Observer Moves

Q. From a bank of a river, the angle of elevation of a tree is 60°. Moving 30 m back, the angle becomes 30°. Find height of tree and width of river.

Setup: width = x m, height = h m

Eq 1: $\tan 60° = h/x$  →  $h = \sqrt{3}x$

Eq 2: $\tan 30° = h/(x+30)$  →  $h = (x+30)/\sqrt{3}$

Equating: $\sqrt{3}x = (x+30)/\sqrt{3}$  →  $3x = x+30$  →  $x = 15$ m

$h = 15\sqrt{3} \approx \mathbf{25.98\ m}$

Type 3 — Tower on Building (ICSE Board 2022)

Q. From a point on ground, angles of elevation of the bottom and top of a transmission tower fixed at top of a 20 m building are 45° and 60°. Find height of tower.

Let d = horizontal distance, h = tower height

Eq 1 (angle 45° to top of building): $\tan 45° = 20/d$  →  $d = 20$ m

Eq 2 (angle 60° to top of tower): $\tan 60° = (20+h)/20$  →  $20+h = 20\sqrt{3}$

$h = 20(\sqrt{3}-1) \approx \mathbf{14.64\ m}$

Type 4 — Angles of Depression from Top

Q. From the top of a 50 m building, angles of depression to the top and bottom of a tower are 45° and 60°. Find height of tower.

Let h = height of tower, d = horizontal distance

Eq 1 (depression 60° to base): $\tan 60° = 50/d$  →  $d = 50/\sqrt{3}$

Eq 2 (depression 45° to top): $\tan 45° = (50-h)/d$  →  $(50-h) = 50/\sqrt{3}$

$h = 50\left(1-\dfrac{1}{\sqrt{3}}\right) = \dfrac{50(\sqrt{3}-1)}{\sqrt{3}} \approx \mathbf{21.13\ m}$

Type 5 — Two Objects on Opposite Sides (Proof Type)

Q. From top of a tower of height h, angles of depression of two objects on opposite sides are α and β. Prove the distance between objects is $h(\cot\alpha + \cot\beta)$.

$d_1 = h\cot\alpha$ (from angle α)    $d_2 = h\cot\beta$ (from angle β)

Total distance $= d_1+d_2 = h(\cot\alpha+\cot\beta)$ ✓

Practice Problems — Heights & Distances
Q1. The angle of elevation of the top of a building from the foot of a tower is 30°, and the angle of elevation of the top of the tower from the foot of the building is 60°. If the tower is 50 m high, find the height of the building.   [4M]
Hint: Let height of building = h, distance = d. tan60° = 50/d and tan30° = h/d. Divide: h/50 = tan30°/tan60° = (1/√3)/√3 = 1/3 → h = 50/3 ≈ 16.67 m. Ans: 50/3 m
Q2. Two poles of equal height stand on either side of a road 80 m wide. From a point between them, angles of elevation of their tops are 60° and 30°. Find height of poles and position of point.   [5M]
Solution:
Let point be x m from first pole. tan60° = h/x and tan30° = h/(80-x)
√3·h = hx → no: tan60°= h/x → x = h/√3. tan30°= h/(80-x) → 80-x = h√3
Adding: 80 = h/√3 + h√3 = h(1/√3 + √3) = h·4/√3 → h = 20√3 m. x = 20 m from one pole.
Ans: Height = 20√3 m; point is 20 m from one pole (60 m from other).
Q3. From the deck of a ship 12 m above water, angle of elevation of top of cliff is 60° and angle of depression of base of cliff is 30°. Find distance of cliff and height of cliff.   [4M]
Solution:
Depression 30°: tan30° = 12/d → d = 12√3 m
Elevation 60°: tan60° = h'/d (where h' = cliff height above ship level) → h' = 12√3·√3 = 36 m
Total cliff height = 36 + 12 = 48 m
Ans: Distance = 12√3 m; Height of cliff = 48 m
Q4. An aeroplane at 3000 m height passes vertically over another aeroplane. The angles of elevation of the two planes from a point on the ground are 60° and 45°. Find the vertical distance between them.   [4M]
Solution:
Let d = horizontal distance from observer to point below planes.
Upper plane: tan60° = 3000/d → d = 3000/√3 = 1000√3 m
Lower plane: tan45° = h₂/d → h₂ = d = 1000√3 m
Vertical gap = 3000 − 1000√3 = 1000(3 − √3) ≈ 1267.9 m
Q5 (HOTS). From a point P on ground, angle of elevation of top of a 10 m tall building is 30°. A flag on the building makes angle of elevation 45° from P. Find length of flagstaff and distance of building from P.   [5M]
Solution:
tan30° = 10/d → d = 10√3 m
tan45° = (10+L)/d → 10+L = d = 10√3 → L = 10(√3 − 1) ≈ 7.32 m
Ans: Flagstaff = 10(√3 − 1) m; Distance = 10√3 m

Tips for ICSE Board Exams
  1. In proving questions, always work on one side only. Changing both sides is incorrect.
  2. Write LHS = … = RHS ✓ at the end — this is essential for full marks.
  3. In Heights & Distances, always draw a clear diagram first — it earns 1 mark even if calculation is wrong.
  4. Leave surd answers like $20\sqrt{3}$ m unless asked for decimal approximation.
  5. Rationalise denominators: Never leave $\sqrt{3}$ or $\sqrt{2}$ in denominator in final answer.
  6. Angle of elevation = Angle of depression between two points (alternate interior angles).
  7. $\tan 90°$ is undefined (∞). Never write a numerical value for it.

PYQ — Heights & Distances
ICSE 2024: A boy standing on ground flies a kite with 100 m of string at elevation 30°. A girl on roof of 20 m building flies her kite at elevation 45°. Both on opposite sides of both kites. Find string length for the second boy so the kites meet.   [4M]
Hint: Height of first kite = 100×sin30° = 50 m. Girl's kite must meet at height 50 m. Girl is 20 m above ground, so kite is (50−20) = 30 m above her. String = 30/sin45° = 30√2 ≈ 42.43 m. Ans: 30√2 m
ICSE 2022: From a point on ground, angles of elevation of bottom and top of a 20 m building with a transmission tower are 45° and 60°. Find height of tower.   [4M]
Ans: 20(√3 − 1) m ≈ 14.64 m (fully solved as Example 3 in Type 3 above)
ICSE 2019: An aeroplane at altitude 250 m observes two boats on opposite banks at depression angles 45° and 60°. Find width of river.   [4M]
Solution:
$d_1 = 250/\tan 45° = 250$ m  |  $d_2 = 250/\tan 60° = 250/\sqrt{3}$ m
Width $= 250 + 250/\sqrt{3} = 250\left(1+\dfrac{1}{\sqrt{3}}\right) = \dfrac{250(\sqrt{3}+1)}{\sqrt{3}} \approx \mathbf{394.3\ m}$

HOTS — Higher Order Thinking Problems

HOTS Challenge Problems
Q1. If $\sec\theta + \tan\theta = p$, prove that $\sin\theta = \dfrac{p^2-1}{p^2+1}$.   [4M]
Hint: $\sec\theta-\tan\theta = 1/p$ (conjugate product = 1). Add/subtract to get sec and tan individually. Use $\sin\theta = \tan\theta/\sec\theta$.
Q2. Prove: $\sqrt{\dfrac{1+\sin\theta}{1-\sin\theta}} + \sqrt{\dfrac{1-\sin\theta}{1+\sin\theta}} = 2\sec\theta$   [4M]
Hint: Each root simplifies to (1±sinθ)/cosθ. Sum = (1+sinθ+1−sinθ)/cosθ = 2/cosθ = 2sec θ ✓
Q3. If $x = r\sin\theta\cos\phi$, $y = r\sin\theta\sin\phi$, $z = r\cos\theta$, prove $x^2+y^2+z^2 = r^2$.   [4M]
Solution:
$x^2+y^2 = r^2\sin^2\theta(\cos^2\phi+\sin^2\phi) = r^2\sin^2\theta$
$x^2+y^2+z^2 = r^2\sin^2\theta + r^2\cos^2\theta = r^2(\sin^2\theta+\cos^2\theta) = r^2$ ✓
Q4 (Classic HOTS). A vertical tower stands on a horizontal plane, surmounted by a flagstaff of height h. The angles of elevation of the bottom and top of the flagstaff from a point are α and β. Prove that the height of tower = $\dfrac{h\tan\alpha}{\tan\beta - \tan\alpha}$.   [5M]
Hint: Let tower height = T, distance from point = d. tan α = T/d and tan β = (T+h)/d. From first: d = T/tan α. Sub in second: T+h = d·tan β = T·tan β/tan α → T(tan β − tan α) = h·tan α → T = h·tan α/(tan β − tan α) ✓
